About This Project

This system explores cognitive workload estimation using typing behavior and micro-behavior analysis. It collects typing speed, pause duration, backspace count and keyboard intervals to build a machine learning dataset.


Machine learning will be used in a later stage to estimate Low, Medium and High workload categories. These estimates are experimental and are not medical or psychological diagnoses.
